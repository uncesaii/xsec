<CardGrid>
  <Card title="A team of AI agents" icon="rocket">
    A lead agent splits the work across parallel strategies and focused subagents, targeting web apps, APIs, source code, packages, and MCP servers — all inside a scope that's checked on every tool call.
  </Card>
  <Card title="Reproduce before trusting" icon="approve-check-circle">
    A separate, blind agent re-exploits each finding seeing only the PoC. Anything it can't reproduce is dropped — never shipped as "low confidence."
  </Card>
  <Card title="Real CVEs, not leaderboards" icon="star">
    XSEC's research loop has disclosed real bugs in the Linux kernel and widely-used open source, with maintainer review from Intel, NVIDIA, Red Hat, Google, and more.
  </Card>
  <Card title="Binary analysis, no source" icon="document">
    When there's only a compiled binary, the in-repo <a href="https://github.com/uncesaii/xsec/tree/main/xverse">xverse</a> engine runs a find → prove → patch → verify loop and confirms a bug only with a reproducing proof-of-vulnerability.
  </Card>
  <Card title="Bring your own model" icon="setting">
    Anthropic, OpenAI, Azure (EU regions), OpenRouter, DeepSeek, Z.ai GLM, Moonshot Kimi, Qwen, a ChatGPT-Codex subscription, or local Ollama — with a hard per-run cost ceiling.
  </Card>
  <Card title="Evidence you can inspect" icon="list-format">
    Every run keeps its own SQLite state, an append-only journal, and artifacts under <code>~/.xsec/runs/</code> — so you can <code>resume</code>, <code>replay</code>, or <code>disclose</code> it later.
  </Card>
</CardGrid>
